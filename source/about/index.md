## 关于这个站点

这是一个用 **Hexo** 生成的纯静态博客，主题是 [AnZhiYu（安知鱼）](https://github.com/anzhiyu-c/hexo-theme-anzhiyu)，托管在 **GitHub Pages** 上，代码推送后由 GitHub Actions 自动构建发布。

没有服务器、没有数据库，所有内容都是仓库里的 Markdown 文件 —— 换电脑、回滚、备份都很简单。

## 技术栈

| 部分 | 选型 |
| --- | --- |
| 静态站点生成 | Hexo 8 |
| 主题 | hexo-theme-anzhiyu（npm 安装） |
| 模板 / 样式 | Pug + Stylus |
| 托管 | GitHub Pages |
| 持续部署 | GitHub Actions |
